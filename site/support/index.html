Frequently asked questions

I forgot my master password. Can it be reset?

No. PassVault has no remote account, recovery key held by the publisher, or server-side copy of your vault. You need the correct master password or an accessible enrolled biometric on the original device. An encrypted backup still requires its separate backup password.

Why did biometric unlock stop working?

Biometric enrollment changes, device security changes, operating-system restrictions, or removal of the protected key can invalidate access. Unlock with the master password, then disable and enroll biometric unlock again in Security settings.

How should I protect a backup?

Choose a unique backup password, keep the encrypted .pvault file and its password separately, and test restoration before relying on it. Do not rename an arbitrary file to .pvault or edit backup contents.

Why is a TOTP code rejected?

Confirm the device date and time are correct and automatic, then verify the login’s setup key, algorithm, digit count, and period match the service. PassVault does not synchronize device time.

How do I move an account?

Open the account details, choose edit, select the destination folder, and save. Select “No folder” to return it to the top level.

Before reporting a problem

  • Install the latest available build from the same distribution channel.
  • Restart the app and reproduce the issue without deleting your vault.
  • Record the platform, OS version, app version, and exact non-sensitive steps.
  • Remove passwords, usernames, backup files, QR codes, and verification codes from screenshots.
